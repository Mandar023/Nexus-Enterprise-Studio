     PMC PROPERTY ASSET & WMF PLAN EXTRACTOR (STANDALONE EDITION) v5.5

HOW TO USE (NO INSTALLATION REQUIRED):
-------------------------------------------------------------------------------
1. Double-click "Open-Property-Extractor.cmd" to launch the extractor.
2. Select Extraction Mode:
   - Property Photos Only (.jpg, .png)
   - WMF Vector Plans Only (.wmf, .emf)
   - Both Photos & WMF Plans
3. Choose Source Server / Network Folder:
   - Click "Server 11 (Wards)" for \\192.168.1.11\Panvel_PMC_All_Ward_Wise_Photo_Plan
   - Click "Server 22 (PMC)" for \\192.168.1.22\PMC_Photo_22
   - Click "Server 19 (Files)" for \\192.168.1.19\Files
   - Or click "Browse..." to select any custom folder.
4. Select your Excel / CSV file containing Property Numbers / Owner IDs.
5. Click "START EXTRACTION TO DESKTOP".

FEATURES:
-------------------------------------------------------------------------------
- Multi-Ward Traversal: Automatically traverses all 240+ ward folders on Server 11.
- Flat Direct Output: Dumps all photos and plans directly into one flat desktop folder
  (no confusing ward folder hierarchy!).
- Crystal Reports Safe: Automatically resizes WMF plans to <25 KB with solid white canvas.
- 100% Offline: Works entirely over local LAN with zero internet dependencies.
