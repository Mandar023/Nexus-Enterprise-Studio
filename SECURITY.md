## Reporting a Vulnerability

We take the security of Nexus Enterprise Studio seriously. If you discover a security vulnerability, please follow responsible disclosure practices.

### How to Report

**Please do NOT report security vulnerabilities through public GitHub issues.**

Instead, report them via:

1. **GitHub Private Vulnerability Reporting** (preferred):  
   Go to [Security Advisories](https://github.com/Mandar023/Nexus-Enterprise-Studio/security/advisories/new) and submit a private report.

2. **Direct Contact**:  
   Open a [private issue](https://github.com/Mandar023/Nexus-Enterprise-Studio/security) using GitHub's security reporting feature.

### What to Include

- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact assessment
- Any suggested fixes (optional but appreciated)

### Response Timeline

- **Acknowledgement**: Within 48 hours
- **Initial Assessment**: Within 5 business days
- **Fix & Release**: Depending on severity, within 30 days

## Security Best Practices for Users

- Always download releases from the [official GitHub releases page](https://github.com/Mandar023/Nexus-Enterprise-Studio/releases)
- Keep your installation up to date
- Run the application with appropriate user permissions (avoid running as Administrator unless required)
- Review PowerShell scripts before execution
