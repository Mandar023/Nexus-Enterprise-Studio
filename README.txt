================================================================================
           NEXUS PHOTO & DOCUMENT OPTIMIZER (ENTERPRISE EDITION)
================================================================================

A high-performance all-in-one desktop and CLI utility suite for:
  1. Batch Photo Optimizer (Property photos guaranteed UNDER 25 KB)
  2. PlanPhoto WMF/EMF Vector Solid Pure White Canvas Optimizer (Crystal Reports Safe)
  3. Server Photo & WMF Extractor (Extract property photos to Desktop by Excel list)
  4. Background Remover & Signature Extractor (Paper to Transparent PNG or Solid White)
  5. Govt Exam PDF & Photo Resizer (UPSC, SSC, IBPS, RRB, NTA, MPSC, MahaDBT)
  6. BLOB & SQL Hex / Base64 Live Previewer
  7. OTP & AES-256 Password Decryptor

--------------------------------------------------------------------------------
QUICK LAUNCH:
--------------------------------------------------------------------------------
- Ultra-Fast Turbo Batch Optimizer (12-Core + 32-Thread Selective Backup): Double-click "Launch-Turbo-Batch-Optimizer.cmd"
- Full Graphical UI Suite: Double-click "Open-Nexus-App.cmd" or "Open-PMC-App.cmd"
- 1-Click Background Remover: Double-click "Remove-Background.cmd"
- 1-Click Server Photo Extractor: Double-click "Collect-PropertyPhotos.cmd"
- 1-Click Govt Exam Resizer: Double-click "Open-GovtExam-Resizer.cmd"

--------------------------------------------------------------------------------
SYSTEM REQUIREMENTS:
--------------------------------------------------------------------------------
- Windows 10 / Windows 11 / Windows Server 2016+
- PowerShell 5.1+ (Pre-installed on Windows)
- .NET Framework 4.7.2+ (Pre-installed on modern Windows)
