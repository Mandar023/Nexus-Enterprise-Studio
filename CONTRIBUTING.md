# Contributing to Nexus Enterprise Studio

Thank you for your interest in contributing! :tada:

## Ways to Contribute

- **Bug Reports** - Open an [issue](https://github.com/Mandar023/Nexus-Enterprise-Studio/issues) with steps to reproduce
- **Feature Requests** - Suggest new features via [issues](https://github.com/Mandar023/Nexus-Enterprise-Studio/issues)
- **Pull Requests** - Fork the repo, make your changes, and submit a PR
- **Sponsor** - Support ongoing development at [GitHub Sponsors](https://github.com/sponsors/Mandar023)
- **Star the repo** - Helps more people discover the project

## Getting Started

1. Fork this repository
2. Clone your fork: `git clone https://github.com/YOUR-USERNAME/Nexus-Enterprise-Studio.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`
4. Make your changes and commit: `git commit -m "Add your feature"`
5. Push and open a Pull Request

## Code Guidelines

- Follow existing C# / WPF / PowerShell coding conventions
- Comment your code clearly
- Test your changes on Windows 10/11 before submitting

## Need Help?

Open a [Discussion](https://github.com/Mandar023/Nexus-Enterprise-Studio/discussions) or an [Issue](https://github.com/Mandar023/Nexus-Enterprise-Studio/issues) — we are happy to help!
